# Cash Mobile — Notification CMS

This package is specifically for the Cash Mobile electronic payment app. It does not cover the later telecom application or corporate website CMS scope.

- Cash-Mobile-Notifications-CMS-CR.pdf: original 27-page English change request, Draft v1.0, 20 October 2026.
- Cash-Mobile-Notifications-CMS-Overview-EN.xlsx: eight main CMS sections with brief descriptions and scope notes.
- Cash-Mobile-Notifications-CMS-Requirements-EN.xlsx: detailed source requirements, campaign/import workflows, events, analytics, permissions and acceptance tracking. Prepared 26 October 2026.

Requirements are a proposed target state, not proof of implemented functionality. Customer authentication and financial operations remain authoritative in the payment backend. Generic requirements and synthetic examples only.
