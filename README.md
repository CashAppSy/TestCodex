# Cash Mobile · Android 0.1.4

نسخة اختبار مستقلة لأجهزة Android ARM64، Android 7+، مع Google Play Services لاستقبال FCM.

تستخدم ملف PNG الأصلي المرفق من المستخدم، بشفافيته الأصلية ودون إعادة رسم أو تغيير البكسلات. تم التحقق من مطابقة بكسلات مورد اللوغو داخل APK للملف الأصلي. تظهر الهوية في الواجهة وأيقونة التطبيق والصورة الملونة الكبيرة للإشعار. خلفية Android التكيفية بيضاء، مع مساحة حول اللوغو لمنع قص الكتابة.

في المقدمة تُعرض الصورة من مورد محلي داخل التطبيق. في الخلفية يرسل الخادم الصورة عبر FCM؛ يلزم تحديث Worker ونفاذ الهاتف إلى رابط اللوغو العام. أيقونة شريط الحالة الصغيرة تبقى أحادية اللون وفق متطلبات Android.

الحزمة com.nabdh.testapp، مشروع Firebase nabed-549b0، versionCode 5. توقيع تطوير مطابق للنسخة السابقة؛ ثبت كتحديث دون إزالة التطبيق. لا يحتاج Metro أو Expo Go. لم يُختبر هذا الإصدار على هاتف فعلي داخل بيئة البناء.

الربط من https://testcodex.eng-ali-m-ibrahim.workers.dev باستخدام رمز الأجهزة والربط. اختبر بحملة Android وشريحة test بعد اكتمال نشر الخادم. ملف SHA256 مرفق. لا يحتوي مفتاح حساب خدمة Firebase.
